# Find my letter
***
Game where you have to find the missing letter(s).
## Installation
***
Go to the root folder.
```
$ cd src
```

Compile the files.
```
$ make find_my_letter
```

Launch the tests.
```
$ make tests
```

Remove .o files.
```
$ make clean
```

Compile the files, launch the tests, and remove the .o files.
```
$ make
```

Play the game.
```
$ ./play
```

Remove all files.
```
$ make mrproper
```
